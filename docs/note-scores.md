# 노트 배점

랜덤 선곡과 `/곡검색`의 곡 임베드에서 **노트 배점** 버튼을 누르면 선택한 채보의 노트 수, 배점, 랭크별 TAP MISS 허용 수와 판정별 달성률 감소율을 표시합니다. 곡 재킷은 썸네일로 표시합니다. 버튼 응답은 실행자에게만 보이며 버튼 유효 시간은 5분입니다.

랜덤 선곡을 다시 뽑으면 배점 버튼도 새 채보를 기준으로 계산합니다. 2P 난이도를 선택한 선곡에서는 1P/2P 임베드를 각각 표시합니다. 곡 검색에는 다시 뽑기 버튼이 없습니다. 노트 수가 제공되지 않는 채보는 계산할 수 없다는 안내를 표시합니다.

## 계산 기준

현재 maimai DX 달성률 기준을 사용하며 DX와 ST 채보 모두 동일한 계산식을 적용합니다. FiNALE 이전의 달성률 계산 방식과 DX SCORE는 대상이 아닙니다.

TAP을 1로 보면 HOLD는 2, SLIDE는 3, TOUCH는 1, BREAK 기본 배점은 5입니다.

```text
W = TAP + 2×HOLD + 3×SLIDE + TOUCH + 5×BREAK
TAP 1개의 배점 = 100 / W (%)
BREAK 1개의 최고 배점 = 5×100/W + 1/BREAK (%)
```

기본 배점 합계는 100%, BREAK 보너스 합계는 1%입니다. BREAK가 없으면 보너스 없이 최대 100%로 계산합니다. 따라서 BREAK의 전체 TAP 환산 가중치는 곡마다 달라집니다.

SSS+ 100.5%, SSS 100%, SS+ 99.5%, SS 99%, S+ 98%, S 97%를 기준으로 `floor((최대 달성률 - 랭크 경계) / TAP 배점)`을 구합니다. 허용 MISS 수는 실제 TAP 수를 초과하지 않습니다. 나머지 노트는 모두 최고 판정이며 BREAK 보너스를 전부 획득한 경우입니다. TAP이 없으면 실제 TAP MISS 허용 수는 0입니다.

일반 노트의 GREAT는 배점의 80%, GOOD는 50%, MISS는 0%를 획득합니다. BREAK는 GREAT 세부 판정에 따라 기본 배점의 80%/60%/50%, GOOD는 40%를 획득합니다. BREAK 보너스 획득 비율은 CRITICAL PERFECT 100%, PERFECT 75% 또는 50%, GREAT 40%, GOOD 30%, MISS 0%입니다.

내부 계산은 분수로 수행해 랭크 경계에서 반올림 때문에 허용 수가 달라지는 것을 방지합니다. 화면의 감소율은 달성률 퍼센트포인트이며 소수점 다섯 자리로 표시합니다.
